# `components/ui` — shadcn primitives, mapped onto the palette

Generated by the shadcn CLI, then edited only where this app's design system
needed it. `sidebar.tsx` (773 lines) is the upstream primitive and is exempt
from the 500-line ceiling: it is vendor code we did not write and do not
restructure. Regenerating a primitive from the CLI would drop the edits listed
below — diff before overwriting.

## Change → file

| Change | File |
|---|---|
| Button tiers (primary / secondary / ghost / outline / danger) and sizes | `button.tsx` |
| Filter / toggle pill | `chip.tsx` |
| The one segmented control (`role=tablist`) | `segmented.tsx` |
| Dropdown menus (glass; the open spring lives on `.glass`) | `dropdown-menu.tsx` |
| Tooltips (glass) | `tooltip.tsx` |
| Dialogs / sheets | `dialog.tsx` / `sheet.tsx` |
| The Ctrl+K palette shell (cmdk) | `command.tsx` |
| Toasts, themed | `sonner.tsx` |
| The sidebar primitive (inner panel is `.glass`) | `sidebar.tsx` |
| Breadcrumb, tabs, badge, card, input, label, separator, scroll-area, skeleton | the file of that name |

## Edits that differ from upstream

- `button.tsx`: five variants and a `danger` tier; `text-on-accent` on the primary fill.
- `dropdown-menu.tsx`, `tooltip.tsx`: `.glass` surface; open animation removed in
  favour of the `.glass[data-state=open]` spring; close animation kept.
- `sidebar.tsx`: the inner `[data-sidebar=sidebar]` panel is `.glass` instead of `bg-sidebar`.
- `../../../tailwind.config.js` maps every shadcn token (`background`, `popover`, `sidebar.*`)
  onto the palette variables, so these files never name a colour.
