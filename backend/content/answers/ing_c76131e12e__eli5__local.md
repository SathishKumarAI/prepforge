Imagine a busy pizza shop that gets dozens of orders every minute. If only one cook handles all the dough, the kitchen will choke and customers wait forever. A **load balancer** is like an efficient manager who watches each incoming order and hands it off to the next available cook so everyone gets served quickly.

In tech terms, a load balancer sits between users (or devices) and a group of servers that run your website or app. When someone asks for a page, the load balancer decides which server should answer, based on rules like “pick the one with the least work right now.” It then forwards the request to that server and sends back the response.

By spreading traffic evenly, it keeps any single server from getting overwhelmed, improves speed, and lets the system keep working even if one server breaks. That’s what a load balancer does—smartly distributing jobs so everything stays fast and reliable.
