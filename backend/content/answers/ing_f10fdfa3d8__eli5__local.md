Think of an IP address like a house number on a street.  
With **IPv4** you have only about 4 billion possible numbers—just enough for the first few million streets in a city. The format is four groups of decimal digits (0‑255) separated by dots, e.g., `192.168.1.1`. It’s short and easy to read but soon runs out of new numbers.

**IPv6** is like expanding that city into a whole continent. Each address has 128 bits, written as eight groups of four hexadecimal digits (0‑9, a‑f) separated by colons, e.g., `2001:0db8:85a3::8a2e:0370:7334`. The extra length gives astronomically more addresses—enough for every grain of sand on Earth and still some left. It also allows built‑in features (like easier routing) that IPv4 can’t easily support.

So, IPv4 is the original, limited address system; IPv6 is the modern, vastly larger version with a different, longer format.
