To judge the student fairly, you give each teacher a fresh set of questions and let them grade independently. You then compare the grades side by side: if the student scores high on both, they’re truly good; if they only do well with one teacher, it shows a bias or a trick.

* **Agentic coding model** – an AI that writes code on its own, not just copies snippets.  
* **SWE‑bench** – a benchmark that tests how useful and readable the code is in real software projects.  
* **TAU‑bench** – a benchmark that checks whether the code is syntactically correct and follows strict style rules.
