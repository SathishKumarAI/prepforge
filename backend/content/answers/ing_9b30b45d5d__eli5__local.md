Think of a computer program as a **recipe book** and the user as a **chef**.  
When you want a dish (the program’s task), you give the chef a clear order: “Make me pancakes.” That command is like typing `python cook.py` in a terminal or clicking an icon. The operating system, acting as the kitchen manager, takes that order and hands it to the right recipe book (the executable file).  

The kitchen manager opens the book, reads each step one by one, and tells the chef what to do next—mix flour, add eggs, heat the pan. Each step is a line of code executed in sequence. If the chef needs more information (user input), he asks: “How many pancakes?” The program pauses, waits for your answer, then continues.  

So, user interaction starts the recipe; the operating system delivers the book; the computer follows each instruction until the dish is finished or an error stops it. This simple flow—order → manager → steps—keeps programs running smoothly.
