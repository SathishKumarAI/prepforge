Think of an AI agent’s memory like a kitchen.

**Structured memory** is the pantry and spice rack—everything has a labeled spot: apples in a basket, salt in a jar, recipes on cards. The agent can quickly fetch “apple” or “salt” because it knows exactly where to look. This is fast but limited to what was pre‑organized.

**Unstructured memory** is the open floor of the kitchen where ingredients spill everywhere—food scraps, sticky notes, half‑finished dishes. The agent doesn’t have a label for each item; it must sift through piles and match smells or textures to decide if something fits a need. It’s slower but can handle surprising, messy information.

So, structured memory is like an orderly pantry: efficient and predictable. Unstructured memory is the cluttered floor: flexible and able to absorb new, unlabelled data, though it takes more effort to find what you want.
