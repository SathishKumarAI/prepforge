Imagine a library that can hold books, but the number it can hold depends on two things: how many shelves (servers) there are and how tall each shelf is (how much memory or CPU each server can use).  
**Cluster capacity** in machine‑learning servers is just that— the total amount of “storage” and “processing power” you get when you combine all the machines in a cluster. It tells you how many data points you can feed, how big a model you can train, and how fast you can run it before you hit a limit.  

- **Server**: A single computer that does the work.  
- **Cluster**: A group of servers working together like a team.  

If your cluster has 10 servers each with 32 GB RAM, its capacity is 320 GB of memory plus whatever CPU and GPU power those servers provide. Knowing this helps you pick models that fit comfortably, just as a librarian would plan space for new books.
