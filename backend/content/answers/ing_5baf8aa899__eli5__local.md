Think of a formatted string like a recipe card that you can fill in with fresh ingredients each time you use it.  
A **formatted string** (often written as `f"…"`) lets you write the skeleton of a sentence and then drop variables right into the blanks, just like writing “{name} likes {food}” and later replacing `{name}` with “Alice” and `{food}` with “pizza.” The braces (`{}`) are the placeholders that the computer sees as “put something here.” When you run the code, Python pulls the current values of those variables, plugs them in, and gives you a ready‑made sentence. This is far simpler than concatenating strings with `+` or using `%` formatting, because the placeholders stay clearly visible inside the text itself.
