Imagine your computer is a kitchen and a machine‑learning program is a recipe for baking a cake.  
The **runtime environment** is the set of appliances (oven, mixer, stove) that let you follow the recipe. When you “run” the program, the operating system first **initializes** this kitchen: it turns on the oven, sets the temperature, checks that all utensils are clean and available, and loads the ingredients into reach.

Once the kitchen is ready, the **interpreter or compiler** reads each line of the recipe (your code) one by one. For every instruction—“mix flour with sugar,” “add 3 seconds of GPU time”—the runtime translates it into machine actions that your CPU, memory, and GPU actually perform.

So initializing the runtime is like setting up a clean, ready‑to‑use kitchen; running the program is then the chef (your code) following the recipe step by step, turning abstract instructions into real work.
