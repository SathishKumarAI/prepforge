**What is Machine Learning?**  
Imagine a robot chef who learns to cook by watching you prepare meals. In supervised learning, the chef (the algorithm) gets many *examples*—a list of ingredients and the final dish’s taste score. Each example has two parts: **input data** (ingredients) and a **label** (taste score). The chef looks for patterns in these pairs and builds a recipe rule set that can predict the taste of new, unseen meals.

- **Input data**: the information fed into the algorithm (e.g., images, text, numbers).  
- **Label**: the correct answer the algorithm should learn to produce (e.g., “cat” for an image, a rating number).

Once trained, the chef can take any new set of ingredients and quickly guess the dish’s flavor, just like a supervised machine learning model predicts outcomes from new data.
