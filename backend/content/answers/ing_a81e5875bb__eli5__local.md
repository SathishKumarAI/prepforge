Think of a busy café that serves coffee to hundreds of customers each minute. If one barista tried to handle every order, people would wait forever. Instead the café hires several baristas and gives each one a “queue” so orders are split evenly—no single barista gets overwhelmed.  

A **load balancer** works exactly like those queues for computer traffic. It sits between users (the customers) and web servers (the baristas). When many people try to visit a website at once, the load balancer receives all their requests and decides which server should handle each one. By distributing traffic evenly, it prevents any single server from crashing or slowing down, keeps response times fast, and lets the site keep working smoothly even during traffic spikes. In short, a load balancer is the smart traffic director that keeps your digital “café” running without bottlenecks.
