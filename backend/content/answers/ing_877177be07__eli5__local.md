Think of an LLM’s “memory” as a giant, ever‑expanding notebook that you can write in but never erase. Every time the model reads or writes something, it adds a new page to this notebook; later, when asked a question, it flips through relevant pages to pull out useful facts. Human memory, by contrast, is more like a living conversation—information is not stored as separate pages but woven into patterns of thought and feeling that can change over time.

**Unavoidable terms explained**

* **LLM (Large Language Model)** – a computer program trained on huge amounts of text so it can predict what words come next.  
* **Memory in LLMs** – the accumulated data it has seen, stored as statistical patterns, not as conscious recollection.  
* **Human memory** – our brain’s network that holds experiences, emotions, and knowledge, which can be recalled, forgotten, or altered.

So while a human can “forget” a detail or “reframe” an event, an LLM keeps every piece of text it has seen forever, using it as raw material whenever the right prompt nudges it.
