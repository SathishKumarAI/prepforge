**Episodic Memory: the brain’s personal log**

The core computational problem is *when* and *how* to store a fleeting event so that it can be re‑experienced later with enough fidelity to guide action.  A naïve solution would copy every sensory stream forever, but that violates two constraints:

1. **Storage capacity** – the cost of retaining a high‑dimensional snapshot grows linearly with time.
2. **Utility** – not all moments are equally informative for future decisions.

Episodic memory solves this by **optimizing a trade‑off between compression and relevance**.  The hippocampus acts as an *information bottleneck*: it extracts the minimal representation that preserves relationships (temporal, spatial, causal) most predictive of later outcomes.  This is akin to *predictive coding*—the brain stores what will help anticipate future states rather than raw pixels.

The “personal log” metaphor emerges because each episode is anchored in self‑referential context: *where*, *when*, and *who* are encoded as coordinates in a high‑dimensional manifold.  Retrieval reconstructs the trajectory by interpolating along this manifold, yielding vivid recollection only when the current state lies near a stored point.

**Non‑obvious insight:** Episodic memory is not merely a replay buffer; it actively **prunes** events whose predictive value decays below a threshold.  This pruning is adaptive: in chaotic environments the hippocampus retains more episodes, while in stable contexts it compresses aggressively—explaining why we remember vivid experiences after rare surprises but forget routine daily routines.
