Imagine you’re learning to play a new video game where the only feedback is points you earn or lose after each move. You don’t get a tutorial; you try different actions, see what happens, and adjust your strategy so that next time you score higher. That’s Reinforcement Learning (RL).

**Key terms**  
- **Agent**: the player (the learning program).  
- **Environment**: the game world it interacts with.  
- **State**: the current situation of the game (e.g., your position, enemies nearby).  
- **Action**: what the agent does (move left, jump).  
- **Reward**: points you receive after an action; a signal telling you if you’re doing well.

The agent explores by taking actions, receives rewards, and updates its “policy” – a rule that tells it which action to pick in each state. Over time, the policy improves so the agent consistently earns more points, just like mastering a game through trial and error.
