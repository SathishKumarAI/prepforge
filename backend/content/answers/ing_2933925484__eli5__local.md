Think of a **branching decision** like choosing a path at a fork in the road.

- **`if`** is the first sign that says, “If it’s raining, take the covered way.”
- **`else`** is the opposite sign: “Otherwise (i.e., if it isn’t raining), take the sunny trail.”

In Python, `if … else` lets your program pick one of two paths.  
The part after `if` checks a condition; if that condition is true, the indented block runs. If it’s false, the code under `else` runs instead.

**Example**

```python
raining = False

if raining:
    print("Take an umbrella.")
else:               # ← this block runs because the condition was false
    print("Enjoy the sunshine!")
```

So “otherwise” simply means *when the preceding test fails*. It’s a clear, human‑readable way to say “if not.” This is the building block for making decisions in any Python program.
