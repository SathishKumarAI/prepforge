**Evaluating agentic systems**

At the core of any *agent* is a **decision problem**: given a history \(h_t\) (past states, observations, actions), choose an action \(a_t\) that maximises future utility.  
The *evaluation* question asks how we can certify that a real‑world implementation actually solves this optimisation problem.

1. **Define the objective function** \(U(h_{t:T})\).  
   It must be a *scalar*, computable from observable traces, and aligned with human values (the alignment problem). Without a precise utility, no test is meaningful.

2. **Establish a performance metric**.  
   Since we cannot observe infinite futures, we approximate by a horizon‑\(k\) return \(R_k = \sum_{i=0}^{k-1} \gamma^i U(h_{t+i})\).  
   The choice of discount \(\gamma\) encodes risk‑aversion and long‑term responsibility.

3. **Construct an evaluation protocol** that is *identifiability*‑robust:  
   a. Randomised environments (oracles) to prevent overfitting;  
   b. Constrained observation windows so the agent cannot cheat by storing private state;  
   c. Repeated trials to estimate variance.

4. **Use statistical hypothesis testing** on \(R_k\).  
   Under the null that the agent behaves like a random policy, we compute p‑values; under the alternative of optimality, we require effect sizes exceeding a threshold.  

5. **Leverage the *no‑free‑lunch* theorem**: any improvement in one task must degrade performance elsewhere unless the agent’s inductive biases match the true environment distribution.  
   Therefore, evaluation should span diverse scenarios to reveal brittleness.

**Non‑obvious insight:** The most reliable indicator of true agentic competence is not raw reward but *policy robustness*—the variance of \(R_k\) across perturbed environments. A low‑variance, high‑mean policy demonstrates that the agent’s optimisation strategy generalises beyond memorised trajectories, revealing genuine problem‑solving rather than overfitting.
