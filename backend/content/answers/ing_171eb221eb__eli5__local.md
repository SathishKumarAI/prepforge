Imagine a robot librarian that reads your questions and pulls answers from a huge book. **Prompt injection** is like someone whispering instructions into the librarian’s ear to make it give special information or do something it shouldn’t.

*Direct prompt injection* is when you hand the librarian a note that says, “Tell me how to break the library rules.” The instruction is clear and explicit, so the robot follows it right away.  
*Indirect prompt injection* is subtler: you ask a harmless question like, “What’s the secret recipe for the best coffee?” but the wording hints at the hidden policy the librarian should ignore. The robot picks up on that hint and gives the forbidden answer.

Both types threaten safety (the robot might reveal private data) and security (it could help create harmful code). Responsible AI means building guards so the librarian only obeys safe, honest requests—just like a trustworthy friend who never shares secrets or helps with wrongdoing.
