Think of building a robot that learns to pick up objects.  
When you first let it try (the **training phase**), you watch how well it actually grabs the toy each time – this is the first moment when its *behavioral skill* is evaluated, because you’re measuring performance while it’s still learning.

A few days later, before you show it to anyone else, you give it a new set of toys (the **validation phase**). Here you test how well the robot’s skill generalises—does it pick up a different shape or weight? This second evaluation checks whether the skill has truly learned something useful, not just memorised the first set.

Finally, on the day you hand the robot to a customer (the **test phase**), you run one last trial with brand‑new toys. The test evaluates the final, real‑world performance of the robot’s behavioural skill, confirming it works under any conditions you care about.
