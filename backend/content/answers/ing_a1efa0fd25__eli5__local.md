Think of the Internet like a huge city where every building needs a street number so people can find it.  
An **IP address** is that street number for a computer or device—“123‑45‑678‑9” instead of “Google.” When you send data (a picture, a video, or a machine‑learning model) across the network, routers read the IP address to decide which road to take next.  
Just as a postal worker uses a house number to deliver mail correctly, network switches use IP addresses to route packets to the right destination.  
In system design, giving each server a unique IP lets you scale services (adding more ML workers), balance traffic, and isolate problems—much like adding new apartments in a city block while keeping everyone reachable.
