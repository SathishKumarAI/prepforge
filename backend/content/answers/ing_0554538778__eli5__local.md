Imagine a detective novel where some words are deliberately hidden behind black‑out sheets. The detective’s job is to guess those missing words from the context around them.  
In **Masked Language Modelling (MLM)** we do exactly that: we take sentences, randomly hide (mask) 15 % of the tokens, and train a neural network to predict each masked word using its left and right neighbours.  

**BERT** (“Bidirectional Encoder Representations from Transformers”) is a library‑ready implementation of this idea. It reads a sentence twice—once normally and once with random masks—and learns how every word relates to everything else in the sentence. After training, BERT can be fine‑tuned for tasks like question answering or sentiment analysis.  

A simple Python snippet:  
```python
from transformers import BertTokenizer, BertForMaskedLM
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForMaskedLM.from_pretrained('bert-base-uncased')

text = "The quick brown [MASK] jumps over the lazy dog."
inputs = tokenizer(text, return_tensors='pt')
preds = model(**inputs).logits
mask_index = torch.argmax(preds[0, 3]).item()
print(tokenizer.decode([mask_index]))   # → fox
```
Here `[MASK]` is the hidden word; BERT predicts “fox” from context. That’s MLM in action—simple, powerful, and a cornerstone of modern NLP.
