**Semantic search** is like asking a very attentive librarian for books that *really* match what you’re looking for, not just ones with the exact keywords you typed.

Imagine you want to find recipes that use “sweet potatoes.” A plain keyword search will pull every page that contains those words—maybe a grocery list or a health article. Semantic search reads the whole context: it understands that “sweet potato” is a vegetable, that “roast” means cooking method, and that “gluten‑free” is a dietary preference. It then ranks results by how well they truly answer your question.

- **How do you build the semantic model?** (What data sources and algorithms power it?)
- **What’s the difference between vector embeddings and bag‑of‑words?** (Why use dense vectors?)
- **How do you handle ambiguous queries?** (Do you ask clarifying questions or guess?)
