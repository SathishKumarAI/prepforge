Think of a video as a long story made up of many pictures that flash quickly, just like a flip‑book. To send or store that story, we need to compress it so the file isn’t gigantic—this is what a *video encoding format* does.

Imagine you’re packing a suitcase: some boxes are heavy but keep everything neat (H.264), others are lighter and let you fit more items even if they’re a bit less tidy (HEVC/H.265). A newer box, HEIF/AV1, is like a collapsible bag that keeps the same amount of stuff while taking up even less space, so you can bring more with you.

**Common formats:**

- **H.264 (AVC)** – the most used “heavy‑but‑efficient” box; works on almost any device.
- **HEVC/H.265** – a newer, lighter version that cuts file size by about half for the same picture quality.
- **AV1** – an open, even slimmer bag that’s gaining ground because it needs less bandwidth while still looking sharp.

All these boxes share the same goal: store the moving pictures so they can be shown again later, but each uses a slightly different packing technique to balance size, speed, and compatibility.
