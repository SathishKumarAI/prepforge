**Program preloading – how a computer starts a program**

Think of your computer like a kitchen and a program as a recipe book you want to read.  
When you decide to cook, the chef (the operating system) pulls the whole book out of the shelf and places it on the counter before you even open the first page. That is *preloading*: the OS reads the program’s files from the hard drive or SSD into RAM, the kitchen’s working space.

Now you can flip to any page instantly because everything is already there; you don’t have to wait for the book to arrive each time you need a new section.  
Once the book is on the counter, the chef (the CPU) starts reading it line by line, turning each instruction into actions—just as your program runs.

So preloading is simply moving a program’s code from storage into fast memory so the computer can execute it right away.
