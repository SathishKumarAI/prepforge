Think of a **UUID** (Universally Unique Identifier) like a passport number that’s guaranteed to be different for every person in the world, no matter when or where it’s issued. It’s generated by algorithms that mix time, random numbers, and sometimes your computer’s network card address, so two people almost never get the same number.

There are five common ways to make such unique IDs:

1. **Random** – toss a long string of random letters and digits; chances of duplication are astronomically low.  
2. **Time‑based** – use the current clock time (down to microseconds) plus a counter so two IDs created in the same second stay distinct.  
3. **Name‑based (hash)** – feed a name or URL into a hash function, turning it into a fixed‑size ID that’s always the same for the same input.  
4. **MAC‑based** – embed your computer’s hardware address (the MAC) so every device has a built‑in unique seed.  
5. **Sequential with namespace** – combine a counter with a “namespace” identifier, useful when you want IDs to be predictable within a certain group.

Each method trades off speed, collision risk, and whether the ID can reveal anything about its origin—just like choosing different kinds of keys for different locks.
