Think of **literals** as the “ready‑made” values you can type straight into a Python recipe without having to prepare them first—like using a pre‑cut carrot instead of chopping one yourself.

In Python there are five basic kinds:

1. **Numbers** – whole (e.g., `42`) or fractional (`3.14`).
2. **Strings** – text wrapped in quotes (`"hello"`).
3. **Bytes** – binary data written as `b'abc'`.
4. **Booleans** – the two truth values, `True` and `False`.
5. **None** – a special value that means “nothing”.

When you write one of these directly in code, Python knows exactly what it is; no extra calculation or lookup needed. That’s why they’re called *literals*—they literally represent the value itself.
