**Var vs Value – like a label on a storage box**

Think of a *value* as the actual thing inside a box: a number, a word, or a picture. It’s fixed until you decide to change it.

A *var* is the name you give that box so you can talk about it later—“this is my favorite color” instead of writing out the whole color each time. In programming, `var` declares a variable: an address where data lives. You can store different values in that same address over time.

So, *value* = what’s inside; *var* = the label you use to refer to it and possibly change what’s inside later.
