**Round‑Trip Time (RTT)** is the time it takes for a tiny data packet to travel from your computer to a web server and back again.  
Imagine you’re sending a postcard to a friend: you hand it over, the postal service delivers it, they read it, write a reply, and send it back. The total time from handing it out until you receive the reply is like RTT.

In website performance, RTT matters because every request for an image, script or style sheet starts with this back‑and‑forth handshake. A high RTT means more waiting before any content appears, which feels slow to users.  
Other key metrics—**First Contentful Paint (FCP)**, **Largest Contentful Paint (LCP)**, **Time to Interactive (TTI)**, **Cumulative Layout Shift (CLS)**, **Speed Index**, **Total Blocking Time (TBT)**, **Request Count**, and **Transfer Size**—measure when things show up, how stable the page is, and how much data moves. Together they give a complete picture of user experience; ignoring any one leaves you with blind spots in performance.
