**On‑policy distillation** is like teaching a new student by watching them solve problems while they’re actually working on the task, not just from a textbook.

*Machine learning model*: a computer program that learns patterns from data (think of it as a “student” that practices solving puzzles).  
*Policy*: a rule set telling the model what action to take in each situation (like a recipe for choosing moves).  
*On‑policy*: using the same policy while gathering new examples; the student’s own choices drive the learning data.  
*Distillation*: compressing knowledge from one or several “expert” models into a single, simpler model—like summarizing a long lecture into concise notes.

In on‑policy distillation, you let an expert model act in an environment (it chooses actions based on its policy), record those decisions and the resulting rewards, then train a smaller student model to mimic the expert’s behavior *while it is still acting* in that same setting. The student learns directly from fresh, real-time examples generated by the expert, ensuring the distilled knowledge remains relevant to the exact task at hand.
