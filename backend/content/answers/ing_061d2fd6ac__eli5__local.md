**Short‑Term Context in an AI system is like a kitchen counter that holds only the ingredients you’re using right now.**  
When you start cooking (a new conversation or task), the AI “puts” the latest question, the user’s name, and any recent answers on the counter. It can read, update, or erase these items quickly because they are close at hand. But after a while—say once you finish the dish—the counter is cleared; those ingredients are no longer available unless someone puts them back.  

**Context = information that the AI keeps handy for the current interaction.**  
It’s “short‑term” because it lives only as long as the conversation or task lasts, then it disappears so the system can stay focused and not be cluttered with old data. This helps the AI answer promptly while protecting older, possibly irrelevant details.
