Think of a long, single‑line hallway with numbered lockers. Each locker holds exactly one item—no rows or columns, just a straight line. In computing, **one‑dimensional indexing** is the same idea: you have a list (or array) that runs in a single direction, and each element gets a single number that tells you where it sits. The number starts at 0 for the first item, then 1 for the next, and so on. Just like you walk down the hallway to find locker 5, a program uses index 5 to fetch the fifth element in the list.
