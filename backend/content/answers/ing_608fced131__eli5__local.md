Think of an “agent” like a tiny robot that follows a set of instructions to get a job done—like a kitchen helper that only knows how to whisk eggs. You’d build it if the task is clear, repeatable, and you can write rules for every situation.

But don’t bother when:

* **The goal is too vague** – If you just want “a good conversation” but never say what topics or tone matter, the robot has no map to follow.
* **Data are missing or biased** – An agent learns from examples. If your data are incomplete or skewed, it will learn wrong habits.
* **Safety matters most** – In life‑or‑death areas (medical diagnosis, nuclear control) a simple rule‑based agent can’t handle every edge case; human judgment is essential.
* **You need deep creativity** – An agent can mimic patterns but can’t invent truly new ideas or art.

In short, build an agent when the task is well defined, data are reliable, safety risks are low, and you don’t need original insight. If any of those fail, a human (or a different tool) is the better choice.
