1. **Registration** is the paperwork you file so each city knows your kitchen (the app) exists.

   - *Certificates & keys*: Digital passports that prove you’re the real owner; they let your code run on users’ phones.

   - *iOS (Swift/Objective‑C)*: The language Apple uses, with Xcode as the chef’s notebook.  
   - *Android (Kotlin/Java)*: Google’s language, with Android Studio as the cookbook.  
   - *ML integration*: You embed a trained model (a recipe) into the app so it can make predictions on device.
