Think of a library that wants every book to be catalogued the same way so readers can find them instantly. OpenTelemetry’s GenAI semantic conventions are the “cataloguing rules” for data produced by generative AI (like ChatGPT). They tell developers how to label each piece of information—what model was used, what prompt was sent, how long the response took, and whether the output was edited—using a standard set of tags.  

Why care? If every team follows the same conventions, you can mix data from different projects, run dashboards that compare performance, and spot problems without reinventing the wheel each time. It’s like having a universal library card: anyone who knows the system can pull up exactly what they need, no matter where it was created.
