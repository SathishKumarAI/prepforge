**Duties**

- **Build the kitchen** – design the model’s architecture (the “recipe book”) and choose which data to feed it.
- **Train the cook** – run massive training sessions, adjusting parameters so the model learns language patterns.
- **Taste‑test and refine** – evaluate performance on real tasks, spot biases or errors, and fine‑tune the model.
- **Serve safely** – implement safety filters, monitor usage, and update the model as new data arrives.

- Strong coding skills (Python, PyTorch/TensorFlow).
- Understanding of machine learning fundamentals—loss functions, gradients, overfitting.
- Familiarity with large‑scale computing (GPUs/TPUs) and cloud platforms.
