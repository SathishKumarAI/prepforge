Imagine you’re building a custom robot that must pick up apples from a tree, but the farmer only tells you what the robot should do—not how to build it. In machine learning, we write those “what” instructions in *requirements notation*: short, clear statements like “The model must correctly classify 95 % of fruit images.”  
Conventions are the rules that keep everyone speaking the same language: we use **uppercase letters** for key terms (e.g., MODEL, DATA), **italic** for variables (like *x* for input image), and **bullet points** to list constraints. We also add a “confidence level” (e.g., *p > 0.9*) to show how sure we are about each requirement.  
Together, notation gives the exact goals, while conventions ensure that developers, data scientists, and stakeholders read the same page without confusion—just like a shared recipe for our apple‑picking robot.
