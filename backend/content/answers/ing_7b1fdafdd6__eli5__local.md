Think of an **AI agent** as a smart robot helper that can walk into any room (a task) and decide what to do there.  
When the room has a toolbox, the agent can pick up a hammer, screwdriver, or phone—this is **tool use**: it’s not just talking; it actually grabs and uses external programs or APIs to finish the job.  

Now imagine you’re interviewing for a role that needs this robot helper. The interviewer asks three kinds of questions:

1. **Agents** – “How would you design a system that can act autonomously?”  
2. **Tool Use** – “Show me how your agent calls an external API to get weather data.”  
3. **MCP (Multi‑Task Coordination Protocol)** – “Explain how the robot keeps track of several tasks at once, like answering a call while cooking.”

The MCP is simply a set of rules that let the agent juggle many tools and goals simultaneously, keeping each task on schedule without dropping any. In an interview, you’ll be asked to describe both the logic (how it decides) and the plumbing (how it talks to other software).
