**Isolation Trees for Anomaly Detection – a principled view**

The core problem is *identifying points that lie in regions of the data space with very low density*, i.e., unlikely to be generated by the underlying process.  
Rather than estimating that density directly (which would require kernel bandwidths, histograms, or parametric assumptions), isolation trees take a **combinatorial view**: an anomalous point is *easily separable* from the rest of the data because it can be isolated by few random cuts.

1. **Random split construction**  
   For each node we pick a feature \(j\) uniformly and a cut‑value \(c\) uniformly in \([x_{\min}^j,x_{\max}^j]\).  
   This generates a *random binary partition* of the space, equivalent to drawing a random hyperplane orthogonal to one coordinate axis.

2. **Isolation cost**  
   The path length \(h(x)\) from root to leaf for point \(x\) counts how many such cuts are needed before \(x\) becomes its own leaf.  
   For a uniform distribution in an \(n\)-dimensional unit hypercube, the expected depth is \(\mathcal{O}(\log n)\).  
   Anomalies, being far from dense regions, fall into small sub‑cubes early, yielding *short* paths.

3. **Probability interpretation**  
   The average path length over many trees estimates the log‑probability of isolation:  
   \[
   s(x,n) = 2^{-\frac{E[h(x)]}{c(n)}},
   \]
   where \(c(n)\approx 2\ln(n-1)+0.5772\).  
   Thus an anomaly gets a high score because it has a low isolation probability.

**Non‑obvious insight:**  
The *distribution of path lengths* across trees is more informative than the raw depth of a single tree. Even if a point lies near a dense cluster, a few trees might happen to split along its direction early, giving it an anomalous score. Therefore, isolation forests exploit *ensemble variance*—a subtle form of stochastic regularization—to amplify true outliers while suppressing noise.

In short, anomaly detection via isolation trees is an elegant application of **information‑theoretic surprise**: points that can be encoded with fewer random cuts are statistically improbable and thus flagged as anomalies.
