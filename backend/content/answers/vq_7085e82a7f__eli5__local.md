Think of a vending machine that sells drinks.  
When you pick a soda, the machine gives you a **price** in dollars – a single number that can be any value from $0.50 to $5.00. That’s like *regression*: the computer predicts a continuous value (the price) based on what it has learned.

Now imagine another vending machine that only tells you whether a drink is **hot or cold**. You just get one of two words, “Hot” or “Cold.” That’s *classification*: the computer chooses from a set of categories (here, two).

So, regression = predicting a real‑valued number; classification = picking a label from a list. Both use past data to make future guesses, but they answer different kinds of questions.
