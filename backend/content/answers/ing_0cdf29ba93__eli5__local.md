**Context Retrieval & Context Engineering**

Imagine you’re a detective who only knows the crime scene if you can pull out the right clues from a huge file cabinet.  
*Context retrieval* is the trick of searching that cabinet quickly—finding the exact notes, photos, or witness statements that matter for the case at hand. In machine learning, it means pulling relevant past data (texts, images, numbers) so a model has the “right background” before answering a question.

*Context engineering* is like deciding how to organize those clues: you choose which folders to keep, what labels to add, and how to summarize each file so the detective can read them fast. In practice, it’s designing prompts or data‑selection rules that guide the model to use only the most useful information, improving accuracy and speed.

So, context retrieval fetches the needed pieces; context engineering shapes and curates them for the best results.
