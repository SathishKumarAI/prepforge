**Quick‑start guide to common PC hardware and peripherals**

| Item | What it is | Why it matters |
|------|------------|----------------|
| **Desktop (PC case)** | Enclosure that holds all parts. | Protects components, provides airflow, determines upgrade space. |
| **Monitor** | Visual display unit. | Shows output from GPU/CPU; resolution, refresh rate affect work and gaming. |
| **Pen drive / USB stick** | Portable flash memory on a USB interface. | Easy data transfer, backup, boot media. |
| **Hard drive (HDD)** | Magnetic storage spinning disks. | Large capacity, cheaper per GB, slower than SSD. |
| **Solid‑state drive (SSD)** | Flash‑based storage with no moving parts. | Much faster read/write, lower power use. |
| **Memory card** | Small flash memory used in cameras, phones, etc. | Portable, removable; formats: SD, microSD, CF. |
| **Computer accessories** | Peripherals like keyboards, mice, speakers, webcams. | Expand functionality and user experience. |
| **Graphics card (GPU)** | Dedicated processor for rendering images/videos/games. | Offloads work from CPU, essential for 3D graphics & AI inference. |
| **CPU (Central Processing Unit)** | Main “brain” that executes instructions. | Determines overall performance; core count, clock speed matter. |
| **Power supply unit (PSU)** | Converts mains AC to regulated DC for components. | Must match power draw and have enough connectors/efficiency. |
| **Motherboard** | Circuit board connecting all parts via sockets & buses. | Hosts CPU socket, RAM slots, PCIe lanes, chipset functions. |
| **Cooling devices** | Fans, heatsinks, liquid coolers. | Keep components within safe temperature limits. |
| **TV card (Video capture)** | Interface to record/display video signals (HDMI, VGA). | Used for streaming, recording, or connecting legacy displays. |
| **Other computing components** | RAM, optical drives, expansion cards, networking modules. | Each serves a specific data‑handling or I/O role. |

### How they fit together
1. **Power** → PSU powers motherboard, drives, GPU, cooling.  
2. **Motherboard** routes signals: CPU ↔ RAM, PCIe lanes to GPU/TV card, SATA to HDD/SSD.  
3. **CPU + GPU** process data; monitor displays the result.  
4. **Storage (HDD/SSD)** holds OS and files; removable media (pen drives, memory cards) transfer data.  
5. **Cooling** keeps CPU/GPU temperatures in check.  

Understanding these roles lets you troubleshoot, upgrade, or build a system that meets your ML workload—whether it’s training on a GPU‑rich workstation or deploying models on an edge device.
