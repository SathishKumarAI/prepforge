In computer science a **table** is simply an organized grid that lets you look up information quickly—just like a phone book. Imagine a bookshelf where each shelf holds a card labeled with a name (the key) and the card’s back has the phone number (the value). When someone asks for “Alice,” you slide down to the right shelf, find her card, and read the number on the back. In code we build this “shelf” as an array or list of slots; each slot can store a pair “key → value.” The magic is that we can jump straight to the correct slot using the key’s hash (a short address), making searches almost instantaneous. That’s what most people mean when they say “table” in data‑structure discussions.
