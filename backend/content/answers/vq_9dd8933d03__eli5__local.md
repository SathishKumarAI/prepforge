A **lambda function** is a tiny, unnamed helper you can create on the spot to do one quick job—like a short note you hand out instead of writing a whole letter.

Imagine you’re in a kitchen and need a quick seasoning mix: “Just sprinkle salt and pepper.” You don’t write a recipe book; you just shout it out. In Python, that shout is `lambda x: x + 1`. It takes an input (`x`), adds one, and gives the result back instantly.

Key terms:
- **Function** – a reusable piece of code that does something.
- **Anonymous** – no official name; you just use it where you need it.

So a lambda is a quick, nameless function used when you only need a simple operation once.
