Think of each date as a stop sign on a long road trip.  
The first column is where you started, the second is where you ended.  
Just like you would measure how many miles are between two stops, you can count how many days (or hours, minutes) lie between two dates.

In a database table, give each date column a name—say `start_date` and `end_date`.  
Most query languages have a built‑in “difference” function that takes the later date minus the earlier one.  
For example, in SQL you can write:

```sql
SELECT DATEDIFF(day, start_date, end_date) AS days_between
FROM trips;
```

`DATEDIFF` is like a calculator that tells you exactly how many whole units of time separate the two stops.  
That single line gives you the time difference for every row in the table.
