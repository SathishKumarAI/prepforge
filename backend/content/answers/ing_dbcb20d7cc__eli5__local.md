Think of a sentence you want to say aloud, but you need to tell your friend exactly where it starts and ends—otherwise they might read extra words or miss the whole thought. In Python we use **double quotes (`"`)** (or single quotes) to mark the beginning and end of a *string*, which is just a piece of text.

Imagine writing a note that says, “Hello, world!” The double quotes are like invisible ink lines:  
`"Hello, world!"`

Everything between those two lines becomes one object in the program. If you forget a closing quote, Python gets confused and will throw an error, just as a sentence with missing punctuation feels incomplete.

So, whenever you want to store or display text, wrap it in double quotes—Python will then treat that block of characters as a single string value ready for use.
