**Error analysis in AI** is like a detective looking at every mistake a computer makes while solving a puzzle.  
Imagine you’re teaching a child to sort colored blocks into boxes. After each round, you check which blocks ended up in the wrong box and why—maybe the child mixed up “red” with “orange” or forgot about “blue.” You then use that information to adjust the lesson: add clearer labels, give extra practice on tricky colors, or change the sorting rules.

In AI, the “child” is an algorithm, the “puzzle” is a task (e.g., translating text), and the “boxes” are correct outputs.  
**Unavoidable terms:**  
- **Model** – the AI program that makes predictions.  
- **Prediction** – the model’s answer to a given input.  
- **Ground truth** – the true, correct answer used as a benchmark.

By cataloguing each error and its pattern, developers refine the model—just as a teacher tweaks lessons after reviewing missteps—to make it more accurate over time.
