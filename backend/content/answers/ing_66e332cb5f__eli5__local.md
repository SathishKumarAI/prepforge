Imagine you’re building a smart kitchen robot that can recognize dishes and suggest recipes. **Deploying** is like installing that robot in your home kitchen so everyone can use it—putting the code on a server, giving it a name (an “endpoint”), and making sure it talks to the internet safely.  

Once it’s there, **maintaining** is keeping the robot happy and accurate:

- **Updating** is feeding it new dish photos so it learns fresh styles, like adding a recipe book.  
- **Scaling** is having more robots in different kitchens if many people start using the service at once.
