Imagine your house has several doors—front, back, garage—and each door can be locked in different ways. **Access control** in computer security is like those locks and keys: it decides who (or what) gets to open which “door” to a piece of data or service.

* *Who*: the user or program requesting access.  
* *What*: the resource (file, database, API).  
* *When/How*: the conditions—time limits, location, device type.

Just as you might give a spare key only to trusted family and a keypad code to guests, an access‑control system grants rights based on rules: “Employee A can read sales data; Employee B can edit but not delete.” If someone tries a door they’re not allowed to use, the lock (the security policy) blocks them. This keeps sensitive information safe while letting legitimate users do their work.
