**Why schema drift matters**

When data moves from a source to a sink, the underlying structure rarely stays constant: new columns appear, types change, or rows are omitted. ADF must still ingest every record without breaking pipelines. The fundamental requirement is *robustness*: the pipeline should accept any incoming schema variation and preserve semantics.

**How ADF solves it**

1. **Dynamic Mapping with Schema Drift enabled**  
   In a Copy activity you toggle *Enable schema drift*. ADF then reads the source metadata at run‑time, automatically generating column mappings for all detected columns. Columns that do not exist in the sink are ignored; new columns are appended if the sink supports them (e.g., Azure SQL with `ALTER TABLE … ADD COLUMN` or ADLS Gen2 with Avro/Parquet dynamic schema).

2. **Type resolution**  
   ADF applies a *type‑resolution strategy* (e.g., “Use source type”, “Cast to target type”, or “Auto”). This ensures that, for instance, a string containing dates is converted to `datetime` in the sink when possible.

3. **Schema mapping file**  
   For more control you can supply a JSON schema map that lists expected columns and types. ADF then performs *column‑level validation*—if an unexpected column appears it’s logged but not mapped, preventing accidental data loss.

4. **Data Flow handling**  
   In Data Flows you can enable *Auto Mapping*. The system infers the schema on each run, allowing dynamic joins or aggregations without hardcoding columns.

**Non‑obvious insight**

The real power lies in *schema evolution* versus *schema drift*. Drift deals with transient changes (e.g., a test column), while evolution concerns permanent changes that must be persisted. ADF’s drift handling is essentially an online, probabilistic inference of the source schema; it treats unknown columns as latent variables and updates the sink schema on‑the‑fly. This statistical view explains why you can safely run pipelines against unstable sources without manual intervention—ADF learns the distribution of column presence over time and adapts its mapping accordingly.
