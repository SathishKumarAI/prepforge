   - **Must‑Have**: Essential for performing the core duties; without it the role cannot function.  
   - **Nice‑to‑Have**: Adds value or efficiency, but the absence won’t cripple the position.

Think of “must‑have” as *critical path* items and “nice‑to‑have” as *optimization* features.

**3. Step‑by‑step reasoning**  
   1. List all tasks in the job description.  
   2. For each task, ask: “What skill is absolutely required to complete it?” → must‑have.  
   3. Then ask: “What extra skill would make this easier or produce higher quality output?” → nice‑to‑have.  
   4. Cross‑check with business impact: if a skill drives revenue or risk mitigation, elevate its priority.

**4. Avoid common traps**  
   - *Overloading* must‑haves: include soft skills that are actually negotiable.  
   - *Underestimating* nice‑to‑haves: treat them as optional when they can be competitive differentiators.  
   - *Bias*: let personal preference (e.g., love for a tool) dictate the list instead of objective need.

**5. Sanity‑check & verbalize**  
   - Run the list by a colleague or subject‑matter expert to confirm each item’s necessity.  
   - When explaining, start with “The must‑haves are… because…” then transition to “Nice‑to‑haves add… but aren’t essential.”
