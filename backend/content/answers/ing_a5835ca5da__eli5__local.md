Think of a company’s information as a huge library.  
A **data architecture** is the blueprint that tells you where every book should go, how shelves are arranged, and which rooms can be accessed by which readers. It lays out the overall structure: warehouses for raw books, shared corridors for common reference, and special sections for quick browsing.

A **data mart** is one of those special sections—say a small, well‑organized “fiction” room that only the marketing team visits. It contains just the stories (data) they need, in a format ready for them to read quickly. The rest of the library remains intact; other departments can still pull from the main shelves if they want.

So, data architecture is the whole library’s design; a data mart is a convenient, department‑specific aisle built on that design.
