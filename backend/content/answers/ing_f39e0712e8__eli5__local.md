Think of machine learning as building a robot that learns to walk.  
The **framework** is the *robot’s skeleton*—the set of bones, joints, and wiring you can use without designing everything from scratch. It gives you ready‑made “walking” routines (like TensorFlow or PyTorch), so you only decide what the robot should learn.

A **driver** is the *brain software* that tells the skeleton how to move in real time. It takes sensor input, runs the learning algorithm, and sends motor commands back to the joints. In code, a driver is the script that loads data, trains a model, evaluates it, and saves the results—essentially orchestrating the framework’s tools.

So, the framework supplies reusable hardware; the driver programs the robot’s behavior, making learning possible without reinventing every part.
