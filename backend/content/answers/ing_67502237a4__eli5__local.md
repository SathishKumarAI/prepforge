**Sandboxing an AI agent**

Imagine a robot that can learn to play any game it’s given. If we let it roam freely on the whole playground, it might bump into other kids or break the equipment. A *sandbox* is like a small, safe sandbox where the robot can practice only with sand, toys, and a clear boundary.

In AI, a **sandbox** is a controlled environment that limits what an agent can see, do, or change in the real world. The agent can experiment—try different actions, learn from mistakes—but its effects stay inside the sandbox. This protects real data, prevents accidental damage, and lets developers test behavior safely before letting the AI run in production.

So, just as a child learns to build with sand without harming the rest of the yard, an AI learns to act without risking the wider system.
