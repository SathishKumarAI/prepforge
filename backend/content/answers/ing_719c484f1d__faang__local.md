The idea is to let designers *explore* and *iterate* freely—using rapid prototyping, component libraries, and internal reviews—to surface design risks early. - **Early “internal” validation:** Peer reviews, usability checks within the team catch obvious flaws before spending time on external testing.
- **User validation later:** When you’ve narrowed down to a few viable design paths, user tests yield more actionable insights (e.g., “this button works”) rather than vague feedback (“I don’t like this color”).
