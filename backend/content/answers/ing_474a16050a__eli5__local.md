**Presentation Layer – The “Translator” of the Internet**

Think of a big international conference where people speak many different languages. Every speaker needs a translator so everyone can understand each other. In computer networking, that translator is called the *presentation layer* (layer 6). It sits right above the transport layer and below the application layer.

**What it does:**  
- **Encodes/decodes data** so any system can read it (e.g., turning text into binary or back again).  
- **Encrypts/decrypts messages**, adding a secret code that only the intended recipient can crack.  
- **Compresses/decompresses files** to make transmission faster, like packing a suitcase more tightly.

In a security cheatsheet, the presentation layer is highlighted because it’s where encryption (SSL/TLS) and data formatting happen—critical spots for protecting information while it travels across networks.
