**Characteristic #3: Thoughtfully Stateful or Stateless**

Imagine a cooking show. A *stateful* recipe remembers what’s been added before – the spices, the simmer time, the amount of broth – so it can adjust later steps. A *stateless* recipe treats each ingredient as fresh, never relying on past choices; every batch starts from scratch.

In machine learning, a **stateful** model keeps track of information over time (like remembering previous words in a sentence), while a **stateless** model processes each input independently, with no memory of earlier data. The key is *thoughtfulness*: the designer decides whether the task needs history (e.g., language translation) or can work cleanly without it (e.g., classifying an image). Choosing the right approach keeps the system simple and efficient, just as a chef picks the right style for each dish.
