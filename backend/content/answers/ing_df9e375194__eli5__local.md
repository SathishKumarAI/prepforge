Think of your app as a kitchen that needs a stove, oven, and refrigerator. In a **server‑based (or “serverless”) architecture** the cloud gives you a ready‑made kitchen: it supplies the appliances, keeps them clean, and turns on only when someone orders a dish.

- **You don’t own or maintain the hardware** – just like renting a fully equipped kitchen, you focus on cooking (writing code) instead of cleaning pots.  
- **Automatic scaling** – if many people order at once, the cloud adds more stoves instantly; if demand drops, it turns them off, so you never pay for idle ovens.  
- **Pay‑as‑you‑use** – you’re billed only for the minutes your code runs, just as a kitchen rental charges by the hour.  

The “serverless” name means there’s no server you need to manage; the cloud handles it all while you concentrate on making tasty meals (your application).
