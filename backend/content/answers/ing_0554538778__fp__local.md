**Masked Language Modelling: the engine behind BERT**

The core problem BERT tackles is *contextual word understanding*: given a sentence with a missing token, can we predict that token? In statistical language modelling this is simply estimating \(P(w_i|c_{-i})\). Traditional n‑gram models approximate this by local context; they fail when long‑range dependencies matter. MLM reframes the task as a *self‑supervised* objective: randomly mask 15 % of tokens, then train a transformer to recover them from both left and right contexts. This turns an unsupervised corpus into a supervised dataset without labels.

Why must we mask? Because if the model saw the target token during training it would trivially copy it. By hiding it, the network is forced to learn *bidirectional* representations—each hidden state encodes information from all positions. The transformer’s self‑attention naturally aggregates this global context, enabling a single forward pass to produce predictions for every mask.

The deeper principle is **information bottleneck**: the model compresses the entire sentence into contextual embeddings that preserve only what’s needed to predict missing words. This compression yields representations that are useful downstream (classification, QA) because they capture syntactic and semantic regularities rather than surface n‑gram frequencies.

A non‑obvious insight: MLM trains *every* token as a potential prediction target, not just the masked ones. Thus, during fine‑tuning, the same encoder can be reused for tasks that require token‑level predictions (NER, POS) without any architectural change—because its hidden states already encode rich, bidirectional information from pretraining.
