Imagine you have a giant library where every book has a long, fancy title (the full web address). A URL shortener is like a librarian who gives each book a tiny, memorable code so people can find it quickly.

**How it works**

1. **Take the long link** – that’s your “book.”  
2. **Generate a unique short code** – think of it as giving the book a new, short name (e.g., `abc123`).  
3. **Store the mapping** – in a simple database table: *short code → full URL*.  
4. **Redirect when requested** – when someone types the short link, the system looks up the code, finds the original URL, and sends them there.

Key terms:
- **URL (Uniform Resource Locator)** – the web address you type into your browser.
- **Database** – a place where data is kept so it can be retrieved later.

The librarian’s job is just to keep an accurate index of short codes to full titles, making navigation fast and easy for everyone.
