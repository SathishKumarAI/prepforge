**Agent‑as‑Judge: Trajectory Grading – Why it Works**

The core problem is *evaluating a long‑form dialogue* without human labels. A trajectory \(T=\{a_1,\dots,a_n\}\) generated by an LLM is essentially a path in a high‑dimensional policy space; we want a scalar score that correlates with “goodness” (coherence, relevance, safety).  
Instead of hand‑crafting metrics, we let the same model *judge* its own outputs. Formally, we define a scoring function
\[
S(T)=\mathbb{E}_{z}\bigl[\log P_{\theta}(z|T)\bigr]
\]
where \(z\) is a “reference” trajectory sampled from a *trusted* policy (e.g., a fine‑tuned LLM on high‑quality data). The expectation measures how well the judged model can reconstruct a trusted path given its own output.  
This aligns with **mutual information**: \(I(T;z)=H(z)-H(z|T)\). Maximizing \(S\) is equivalent to minimizing conditional entropy, encouraging the judged trajectory to be *informative* about a high‑quality reference. It also satisfies the *optimization principle*: if we use \(S\) as a reward in RL‑HF, gradients push the policy toward trajectories that are indistinguishable from trusted data.

**Non‑obvious insight:** The scoring function is invariant under deterministic rescaling of logits because it depends only on log‑probabilities. Thus, even if the judged model has temperature‑tuned outputs, the score remains stable—making it robust to inference‑time hyperparameters that otherwise corrupt naive likelihood comparisons.
