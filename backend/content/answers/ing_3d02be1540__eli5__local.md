Think of an AI like a giant library that keeps books (data) and remembers how to use them when asked.  
Memory benchmarks are the “library audits” that tell us how many shelves it can hold, how fast it can pull a book from deep storage, and whether it can still recall old titles after adding new ones.

* **LoCoMo** (Local‑to‑Global Memory) checks if the AI can quickly move a small set of important facts from its “short‑term shelf” to its larger archive without losing speed.  
* **LongMemEval** tests how well the AI keeps long‑term memories over time, like remembering a story after reading it hundreds of times.  
* **BEAM** (Balanced Efficient Access Memory) measures how evenly the library balances quick access and deep storage—so the AI can answer today’s question while still using knowledge from years ago.

By running these tests in 2026, researchers know whether an AI is a well‑organized, speedy, and reliable librarian or if its memory system needs redesigning.
