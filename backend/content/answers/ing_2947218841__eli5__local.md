Imagine you’re sending postcards to friends all over the world. If every postcard must travel from your home to each friend’s mailbox, some will arrive slowly or even get lost when traffic jams up the road. A **Content Delivery Network (CDN)** is like a network of friendly post offices scattered across the globe that hold copies of those postcards. When a friend asks for one, the nearest post office hands it over instantly, so the message reaches them quickly and reliably.

**Benefits in system design**

1. **Speed** – Delivering content from a nearby server reduces travel time, so pages load faster for users.
2. **Reliability** – If one server fails or traffic spikes, other servers keep serving the same content, preventing downtime.
3. **Scalability** – The CDN spreads traffic across many servers, letting a website handle millions of requests without overloading any single machine.
4. **Reduced bandwidth costs** – Content is cached locally, so the origin server saves on data transfer fees.

In short, a CDN keeps your site snappy, dependable, and ready for lots of visitors, just like having local post offices makes postcards arrive almost instantly no matter where you live.
