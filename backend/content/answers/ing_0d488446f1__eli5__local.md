**Execution Model—Agentic Engineering (Neo Kim & Paul Hoekstra)**  
Think of a machine‑learning system as a **team of robots that can ask for help when they’re stuck**, rather than just following a single recipe.  

* **Model** – the robot’s “brain,” a trained neural network that tells it what to do next.  
* **Execution model** – the rules that decide *when* the robot runs its brain and *how* it talks to other robots or humans.  
* **Agentic engineering** is the idea of giving each robot an *agent*—a tiny decision‑maker that can request extra data, pause for clarification, or hand off a task to another agent if it doesn’t know the answer.

So instead of one monolithic program that blindly processes everything, you have many small agents that cooperate and ask for help. They’re like students in a classroom: each student knows their part but will raise a hand when they need an explanation, making the whole class smarter and more flexible.
