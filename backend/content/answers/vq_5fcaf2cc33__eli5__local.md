Imagine you’re at a pizza shop and you want a custom topping combo that’s only needed for this one order. You don’t need to give the chef a permanent recipe card—just tell them “add exactly one slice of pepperoni and two olives” right now.  
In Scala, an **anonymous function** is like that quick‑hand instruction: it’s a small piece of code written on the spot without giving it a name. You write it with `=>` (read as “goes to”) so the compiler knows you’re turning some input into an output. For example, `x => x * 2` says, “take whatever number comes in and return double that.” It lives only where you use it—just like your one‑time topping list—so you can keep code tidy and focused without cluttering your program with many named functions.
