Imagine a giant library of books (the LLM) that can write stories on any topic.  
**Evaluation** is like a careful librarian who reads each story to check three things:  
1️⃣ *Accuracy* – does the book state facts correctly?  
2️⃣ *Relevance* – is it answering the question asked?  
3️⃣ *Safety* – does it avoid harmful or biased language?  

The librarian gives the book a score, just as we grade code in an interview.  
**Guardrails** are the library’s rules: a filter that blocks any text containing hate speech, personal data, or instructions to do something dangerous. They’re built into the model so that even if the book is creative, it never steps over the line.  

In an ML interview, you’ll be asked how you’d set up these checks—defining metrics for accuracy and relevance, and designing safety filters—to keep a powerful LLM trustworthy and useful.
