Think of a **class** as a blueprint for a cookie cutter and an **object** as the actual cookie you bake from it.  
The class tells your program what ingredients (attributes) the cookie needs—flour, sugar, butter—and how to mix them (methods). When you create an object, you’re using that recipe to make one real cookie with its own flavor: maybe chocolate chip or oatmeal raisin.  

**Encapsulation** is like keeping the dough in a sealed bag; only the cookie‑baking method can touch it, protecting the mixture from accidental changes.  
**Inheritance** lets a new cookie class inherit the original recipe and then add extra sprinkles or drop out an ingredient—just as a “ChocolateChip” class can reuse all of “Cookie”’s code but also adds cocoa.  

So OOP in Python is simply giving your program a way to build, protect, and extend real‑world objects with reusable blueprints.
