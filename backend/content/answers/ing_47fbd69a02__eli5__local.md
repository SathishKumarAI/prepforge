If everyone writes on it, the board gets crowded and hard to read—just like data streaming into a machine‑learning model can overwhelm its “bandwidth,” or how much information it can handle at one time.

When the board fills up too quickly, the teacher must either slow down (wait for more space), simplify what’s written (compress data), or use multiple boards (parallel processing).
