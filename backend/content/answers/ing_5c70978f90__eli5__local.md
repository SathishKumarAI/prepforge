Think of an AI project like building a smart robot that can learn to walk.  
When hiring, interviewers look for *red flags*—signals that the robot might stumble before it even starts walking.

1. **No clear goal** – If the job description says “make something useful” but never specifies what “useful” means, the robot’s path is unclear and it can wander aimlessly.  
2. **Missing safety checks** – Skipping tests for bias or privacy is like letting a robot run without brakes; it may harm people before it learns to walk properly.  
3. **Over‑promising results** – Claiming the model will solve every problem in seconds is like saying a new walker can hop across any obstacle instantly—realistic expectations keep the project grounded.  
4. **No version control or reproducibility** – Without a clear log of changes, it’s hard to know why the robot behaved differently last week, just as a builder cannot fix a broken joint if the blueprint is missing.

These red flags tell interviewers whether the AI role will build a reliable, safe, and well‑documented “smart walker” or simply wander off track.
