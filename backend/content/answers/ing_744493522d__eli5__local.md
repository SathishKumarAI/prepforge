**Scalability in machine‑learning system design** is like running a popular restaurant that must keep every customer happy as the crowd grows.

* **Scalable** means the system can handle more data or users without breaking or getting slow.  
* A *machine‑learning model* is the chef’s recipe, learning from ingredients (data) to make tasty dishes (predictions).  
* The *system design* is the kitchen layout: how many ovens, how food moves, and how orders are split.

Imagine you add more tables (users). If the kitchen has only one oven, everyone waits. To stay scalable, you add extra ovens (parallel servers) and a conveyor belt (distributed data storage) so each order goes straight to an available stove. The recipe stays the same; only the way it’s cooked changes.
