Imagine a toolbox where every tool has a fixed name: “Hammer,” “Screwdriver,” or “Wrench.” In programming, an *enum* (short for enumeration) is like that toolbox’s list of tool names—each name is a constant value you can use in your code. Instead of typing the same string over and over (“hammer”, “screwdriver”), you declare the enum once, and then refer to its items by name: `Tool.Hammer`, `Tool.Screwdriver`. This keeps your code tidy, avoids typos, and lets the compiler check that you’re only using valid options.
