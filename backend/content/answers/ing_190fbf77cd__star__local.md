**Task:**  
Design a database schema that scales horizontally, guarantees uniqueness without collisions, and allows fast read/write for high traffic (≈10k requests/second). I also had to keep storage costs low and enable easy querying of link statistics.

**Action:**

- I added a `clicks` column in PostgreSQL and updated it asynchronously using Kafka events, so writes didn’t block the shortener endpoint.  
- Partitioned the `urls` table by owner ID to keep index size manageable, and used GIN indexes on URL fields for quick lookups during analytics queries.
