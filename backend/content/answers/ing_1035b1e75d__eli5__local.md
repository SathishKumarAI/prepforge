**Quick Glossary – The “AI Cooking Show”**

Think of building an AI model like hosting a cooking show that turns raw ingredients into a dish everyone loves.

| Term | What it is (in the kitchen) |
|------|----------------------------|
| **Dataset** | The pantry full of food items you’ll use. |
| **Pre‑processing** | Washing, chopping, and seasoning—preparing data so the model can “taste” it properly. |
| **Model Architecture** | The recipe book: a set of instructions telling the kitchen how to combine ingredients. |
| **Training** | Cooking the dish: repeatedly mixing ingredients while tasting (calculating loss) until the flavor (prediction accuracy) is right. |
| **Evaluation** | A blind taste test using new food (validation data) to see if the dish still works. |
| **Hyper‑parameters** | The stove heat, cooking time, and spice levels you tweak to improve flavor. |
| **Inference** | Serving the finished dish to guests—making predictions on brand‑new data. |

Just as a chef follows a recipe, cleans ingredients, tweaks spices, tests taste, and finally serves, an AI developer loads data, cleans it, designs a model, trains it, checks performance, tunes settings, and then uses it for real tasks. This cycle keeps the AI “dish” tasty and reliable.
