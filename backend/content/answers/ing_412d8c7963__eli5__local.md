A **coding agent** is like that robot for software: it’s an AI program that follows instructions written in code (the recipe) but can also learn from its own experience.  

*Agent* – a self‑contained system that observes, decides, and acts.  
*Coding* – the set of commands or rules that tell the agent what to do.
