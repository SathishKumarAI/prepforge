Think of a function like a vending machine that turns ingredients into a snack. You put in a set of inputs (money and a button choice), the machine runs its internal recipe (the code inside the function), and then it spits out a result—a chocolate chip cookie or a soda—without you needing to know how it’s baked. In programming, the “ingredients” are variables you pass into the function; the “recipe” is the sequence of instructions; the “snack” is the output value that comes back.

A **function** is just this reusable vending machine: a named block of code that takes inputs (arguments), does something with them, and returns a single result. You can use it over and over in different parts of your program—just like you could keep buying cookies from the same machine whenever you’re hungry.
