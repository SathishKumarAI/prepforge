**Step 5 – “Add Memory”**

Think of an AI agent like a smart robot learning to bake bread.  
When it first starts, it only knows how to mix flour and water. After each loaf, the robot **records** what happened: Did the dough rise? Was the oven too hot? That record is its *memory*.  

Later, when the robot wants to bake again, it looks back at those records instead of starting from scratch. It uses the past notes to decide whether to add more yeast or lower the temperature. In the same way, an AI agent stores past observations and actions in a database (its memory). When new data arrive, it queries this memory to predict better actions or correct mistakes, just like the robot refines its recipe by remembering what worked before.

So, “add memory” means giving the agent a place to keep its learning experiences so future decisions are smarter.
