**What is load balancing?**  
Imagine a busy kitchen where several chefs must cook many orders at once. If every chef takes on all the dishes, some will be rushed and others will wait too long. Load balancing is like having a smart kitchen manager who watches each station’s workload and sends new orders to the chef with the most free space or fastest prep time. In machine‑learning systems, many tasks—training models, running inference requests, preprocessing data—compete for CPU, GPU, memory, and network bandwidth. A load balancer distributes these jobs across servers or GPUs so that no single resource gets overwhelmed while others sit idle. This keeps the system fast, reliable, and cost‑effective, just as a good manager keeps diners happy and chefs efficient.
