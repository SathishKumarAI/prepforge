Think of a team of chefs in a bustling kitchen.  
Each chef is an *agent*—an autonomous decision‑maker that knows how to cook, taste, and plan meals. When the main dish needs a special sauce, instead of making it from scratch, one chef asks another chef (or even a sous‑chef) who already has a perfected recipe. That “other chef” becomes a *tool*: an agent that provides a specific skill or resource on demand.

In AI, **A2A (Agent‑to‑Agent)** means one software agent can call upon another agent to do something it doesn’t do well itself—like translating text, fetching data, or running a simulation. The calling agent sends a request, the tool agent performs the task, and returns the result, just as the first chef receives the sauce from the second. This lets each agent stay focused on its strengths while still achieving complex goals together.
