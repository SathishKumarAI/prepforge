Think of AI as a school where students (the models) learn different subjects.  
A **benchmark** is like a standardized test that every student takes: it asks the same set of questions so we can see how well each one performs on the same material.  
A **leaderboard** is the class roster that shows who scored highest, second best, and so on. It updates as new tests are released or when students improve their answers.

So, a benchmark gives us a fair “exam” for AI models; a leaderboard displays the results in order, letting researchers see which models are leading the pack and where improvements are needed.  
Both tools help keep progress transparent and drive better designs, just like test scores motivate students to study harder.
