**Observability in large‑language‑model (LLM) apps**

Think of an LLM app like a kitchen where recipes (models) cook meals (answers). **Tracing** is the notebook you keep: it records every step—what ingredients were used, how long each stove was on, and which utensils touched the food. In software, tracing logs each “request” that flows through the app, noting time stamps, component names, and any errors.

**Evaluation** is tasting the finished dish. It checks if the answer meets quality standards: is it relevant? Is it safe? Does it respect user privacy?

When you combine tracing and evaluation, you get **observability**—a clear view of how the LLM behaves in real life. If a recipe fails, you can look back at the notebook to see exactly where something went wrong, fix it, and improve future dishes.
