Imagine a smart robot that learns to play chess by watching many games.  
An **AI agent** is like that robot: it receives *inputs* (the board), follows a set of *rules* (its program), and produces an *output* (a move).  

1. **Define the goal** – “win the game.”  
2. **Collect data** – thousands of past games give the agent examples of good moves.  
3. **Teach it** – a learning algorithm looks for patterns: when a board looks like X, the best move tends to be Y.  
4. **Act and learn** – after each play the agent checks if it won or lost, adjusting its pattern‑matching rules accordingly.
