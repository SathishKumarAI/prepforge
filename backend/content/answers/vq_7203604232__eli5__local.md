Imagine your HDFS (Hadoop Distributed File System) as a huge library with thousands of books spread across many shelves. Each book is actually a *file* stored on different computers (the *nodes*). To find a particular text name—say “sales‑report‑2023.txt”—you use Hadoop’s built‑in search command, just like looking up a title in the library catalog.

1. **Open a terminal** and type  
   `hdfs dfs -ls /path/to/directory | grep sales-report-2023.txt`  

2. The `-ls` option lists every file under that directory, and `grep` filters the list to show only lines containing your exact name.

If you don’t know where it might be, run the same command starting at the root (`/`) or use a wildcard:  
`hdfs dfs -find / -name '*sales-report-2023.txt*'`.

Here, *HDFS* is the distributed file system that spreads data across many machines; *nodes* are those machines; and *grep* is just a text filter. This simple “search‑and‑filter” trick lets you locate any file quickly without digging through each node manually.
