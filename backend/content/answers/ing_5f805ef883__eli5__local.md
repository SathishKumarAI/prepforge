Imagine you’re giving a chef (the large language model) a recipe book that lists every kitchen gadget it can use—knives, ovens, blenders—and how each one works. A *tool schema* is just that: a clear, simple description of each gadget’s name, purpose, and the exact “ingredients” (inputs) it needs to start working. The chef reads the recipe, decides which gadget fits the dish (task), then follows the instructions to make a perfect meal.

In AI, we build these schemas so the model can *choose* the right tool for any job—like calling an API to fetch weather data or using a calculator to solve equations—and know exactly what information to give it and how to interpret the answer. This turns a generalist model into a skilled, multitasking kitchen that knows when and how to use each gadget efficiently.
