Think of a URL shortener as a “post office box” for web addresses.  
A long, hard‑to‑remember address (the original URL) is like a full street name and house number that many people would have to write down or type out. The shortener gives it a tiny, easy code—just a few letters or numbers—that you can drop into an email, tweet, or handout.

When someone clicks the short code, the service looks up the “mailbox” (a database) and forwards them to the full address.  
*URL*: a web address that points to a specific page.  
*Shortener*: a program that creates these tiny codes and stores the mapping.  

The key trick is making sure each code is unique and quickly retrievable, just as every post office box has a distinct number so mail goes to the right person.
