Think of training an LLM like teaching a child how to recognize different kinds of fruit.  
You don’t need the entire world’s fruit catalog—just enough samples so the child learns what “apple” looks like in many contexts, and that it isn’t confused with a “pear.”  

For a new feature you’ll usually start with **a few hundred to a couple thousand examples**. That gives the model enough variety to spot patterns without overfitting.  
The examples come from:  

1. **Real user interactions** – snippets people actually write.  
2. **Curated datasets** – clean, labeled text that covers the feature’s domain.  
3. **Synthetic data** – generated by other models or rules to fill gaps.  

Mixing these sources is like giving a child pictures, stories, and hands‑on practice—each helps it learn the feature reliably.
