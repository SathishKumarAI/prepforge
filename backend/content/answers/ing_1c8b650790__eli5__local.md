Imagine the AI is like a giant library that remembers everything it has read.  
A RAG (Retrieval‑Augmented Generation) pipeline is a librarian who, when you ask a question, first looks up the latest book on a shelf and then writes an answer using that fresh page.  

When someone says “just edit the fact into the model’s weights,” they’re asking the librarian to rewrite the entire library: to change every single sentence inside each book so that the wrong information disappears forever.  
Weights are the tiny ink‑drops that make up each word in those books; editing them means re‑printing the whole thing, which is slow, error‑prone, and often leaves other stories broken.  

So, keeping a RAG pipeline lets you add new facts on the shelf without touching the old books—cleaner, faster, and safer for everyone who reads from it.
