**Contextual Retrieval – the “why” and how**

The core problem any search or recommendation system faces is *mapping a user’s intent to the most useful items*. Intent is never fully observable; we only see a noisy cue (a query, a session history). The goal is therefore to learn a function that, given an observed context vector \(c\), predicts which items \(x\) will maximize user satisfaction.

1. **Formulate as an optimization problem**  
   Define a loss \(L(c,x)=\mathbb{E}_{y\sim P(y|c)}[-\log p_\theta(x|c,y)]\).  
   Here \(y\) is the latent intent, and \(p_\theta\) is our retrieval model. Minimizing this loss over \(\theta\) encourages the model to place probability mass on items that would be chosen if we knew the true intent.

2. **Probabilistic modeling of context**  
   Treat \(c\) as a random variable generated by an *embedding network* that captures semantic, temporal and behavioral signals. By training this network jointly with the retrieval head (end‑to‑end), the system learns to compress the high‑dimensional session into a low‑dimensional manifold where similar intents lie close together—a direct application of the *information bottleneck* principle.

3. **Geometry of relevance**  
   Retrieval is then a nearest‑neighbour search in this learned space, but with an *adaptive metric*: distances are weighted by confidence scores derived from the posterior over \(y\). This geometric view explains why simple cosine similarity fails when user intent drifts mid‑session.

4. **Non‑obvious insight**  
   Many implementations treat context as static; however, the *context vector should be updated continuously via a recurrent or transformer encoder*. The hidden state implicitly models a belief distribution over intents that evolves with each interaction—essentially performing online Bayesian inference without explicit sampling.

In short, contextual retrieval is an optimization of a probabilistic intent model, learned jointly with a geometric embedding space, and its efficacy hinges on dynamic context updates that capture the fluidity of user intent.
