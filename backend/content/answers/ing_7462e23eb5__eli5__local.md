Think of a smart assistant as a library that answers questions only if you give it the right book and page number.  
The **prompt** is that “book & page” – a short description or instruction telling the AI what kind of answer you want. It’s the *API surface* because, just like an API call tells a computer program which function to run, the prompt tells the AI exactly which task to perform.

**Prompt engineering** is the art of choosing the best book and page: adding details, examples or constraints so the assistant returns useful, accurate information.  
**Context** is everything you give it along with the prompt—previous questions, user preferences, data snippets—that helps the AI stay on track, like a bookmark that remembers where you left off.

So, by carefully crafting prompts (the API call) and supplying relevant context (the bookmark), you guide the AI to deliver the precise help you need.
