**Read replica** is like having a second copy of the entire library on a quiet floor where people can check out books, but they can’t add new ones there. It’s an exact duplicate of the main shelf, so anyone who needs a book sees the same content that everyone else does.  
**Cache** is like a small “quick‑look” desk near the entrance that holds only the most popular titles. People grab a copy from the desk to read immediately; if they need something not there, the desk asks the main library for it and then keeps a copy for next time.
