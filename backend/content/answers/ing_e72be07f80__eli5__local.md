Think of a web app as a kitchen that serves meals (your site’s pages) to hungry customers (users). In traditional hosting, you own the entire kitchen: you buy ovens, hire chefs, keep them running all day—even when no one orders food, the ovens stay on and consume electricity.  

Serverless computing is like renting a *cooking studio* that turns on only when someone places an order. Amazon Web Services (AWS) provides “functions” (tiny, single‑purpose programs) that automatically spin up, run the requested task, then shut down instantly. You don’t pay for idle ovens; you only pay for the exact cooking time each function uses.  

For a web app, you write small functions for tasks like fetching data or sending emails, and AWS handles scaling, maintenance, and cost‑efficiency—so you focus on designing delicious features instead of managing servers.
