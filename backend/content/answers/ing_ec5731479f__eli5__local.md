**Parallel Context Compaction for Long‑Horizon LLM Agent Serving**

Imagine a robot librarian that must read and remember an entire library’s worth of books to answer questions later. If the librarian tries to hold every page in memory, it gets overwhelmed. “Context compaction” is like letting the librarian first skim each book, write a one‑sentence summary, and keep only those summaries—so the library fits in its mind.  
Now, “parallel” means the librarian does this skimming for many books at once, using several hands (threads). The robot can quickly condense a huge amount of text into short, useful notes, keeping the long‑term plan (the “long horizon”) intact while still being able to answer new questions fast. This lets large language models serve users with deep, multi‑step reasoning without running out of memory or speed.
