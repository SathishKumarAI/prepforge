Imagine you’re ordering a pizza from your favorite shop. **Latency** is the time between placing the order and receiving the first bite—how long it takes for the machine learning system to start giving you an answer after you ask a question.

In a computer, when you send data into a model (the “order”), the network has to route that data through several layers: input preprocessing, hidden calculations, and finally the output layer. Each step adds a tiny delay—just like the pizza shop’s kitchen prep, baking, and delivery. The total latency is the sum of all these delays.

A low‑latency model means you get a quick “cheese‑on‑crust” response; high latency feels like waiting for a hot slice that never arrives on time. Reducing latency—by using faster processors, simpler models, or caching results—is like streamlining the kitchen so you can taste the pizza sooner.
