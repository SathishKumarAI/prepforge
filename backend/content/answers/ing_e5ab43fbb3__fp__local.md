**What Prompt Engineers Do (and why the role is essential)**  
Prompt engineering tackles a core bottleneck in modern LLMs: *the mapping from user intent to model behavior*. An LLM learns a probability distribution over tokens; its output depends heavily on the conditioning context. A prompt engineer designs that context so the stochastic process aligns with a specific task—classification, summarization, code generation, or dialogue—while obeying constraints like length, bias mitigation, and interpretability. The work is essentially *controlled inference*: we steer a generative system by shaping its input distribution.

Prompt engineers aren’t just “writers”; they are **probabilistic constraint solvers**.
