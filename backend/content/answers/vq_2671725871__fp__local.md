**R Markdown** is a lightweight markup language that couples *plain text* with **embedded R code** (and other languages).  
Its fundamental problem: *how do we produce a reproducible document that interleaves narrative, analysis, and output in one file?* Traditional reports separate the “story” from the calculations; when data or code changes the story must be rewritten manually.  

R Markdown solves this by treating the source as a **single source of truth**.  
1. The author writes prose using Markdown (headings, lists, etc.).  
2. Inline R chunks (````{r}``) are executed during rendering; their results—tables, plots, or printed values—are inserted automatically.  
3. A *knitr* engine parses the file, runs the code, captures outputs, and then a *pandoc* converter turns the enriched Markdown into HTML, PDF, Word, etc.

The point is **reproducibility + automation**: any change to data or code propagates instantly through the report without manual copy‑paste.  
A non‑obvious insight: R Markdown’s design mirrors *functional programming*: each chunk is a pure function of its inputs; the final document is a deterministic composition of those functions, making debugging and version control far more tractable than ad‑hoc scripts plus word processors.
