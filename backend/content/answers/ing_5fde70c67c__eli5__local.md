Imagine your favorite streaming service has two identical servers—one is the “primary” and the other is a backup. While you’re watching, the primary server streams the video. If that server hiccups or crashes, the system instantly switches to the backup so you never see a pause. That instant switch is **failover**.

In AI systems, failover means having a duplicate set of hardware, software, or cloud resources ready to take over whenever the main component fails—whether due to a power outage, network glitch, or software bug. The backup runs in parallel but stays idle until needed. When failure occurs, traffic is rerouted automatically, often within seconds, so users experience no interruption.

Key terms:  
- **Primary** – the main system handling requests.  
- **Backup** – an identical copy waiting to step in.  

Failover keeps AI services reliable and available, just like having a spare battery for your phone that kicks in when the first one dies.
