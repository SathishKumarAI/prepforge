Imagine a recipe book that can only hold so many different dishes before it starts to get messy. In machine learning, the **capability** (or “capacity”) of a model is like that limit – it’s how many distinct patterns or recipes the model can learn without getting confused. A simple linear regression has low capacity: it can only draw straight lines. A deep neural network with many layers has high capacity; it can fit very wiggly, intricate curves.

If you give a low‑capacity model too many complex dishes (data), it will “underfit” – it can’t capture all the flavors and makes rough predictions. If you give a very high‑capacity model an overly small set of recipes, it may “overfit” – it memorizes every single dish but fails to taste new ones correctly.

So, capacity is the balance between flexibility (learning complex patterns) and simplicity (avoiding over‑memorization).
