**Inference‑time scaling** is like adjusting the zoom on a camera right before you take a picture.  
When an AI model “infers” (answers a question or makes a decision), it can run faster or slower, and more or less accurately, by changing how much computing power it uses at that moment—just as turning the zoom dial changes how quickly the image is captured.

In an **agentic loop**—the cycle of sensing, deciding, acting, and learning—the AI must often react in real time. If it can scale its inference speed on demand, it can keep the loop tight: a quick, rough answer when it’s urgent, or a slower, more precise one when time allows. This flexibility keeps the agent responsive while still being smart.
