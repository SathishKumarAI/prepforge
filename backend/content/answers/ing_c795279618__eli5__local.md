Imagine the internet as a giant post office where every computer is a mailbox and every message or file is a letter. **FTP (File Transfer Protocol)** is the “express delivery” service that tells a sender’s computer how to package, label, and hand over a file so it can be picked up by the receiver’s computer.

- **How it works**: The sender’s computer opens an FTP “post office window,” logs in with a username and password (the lock‑screen), then hands the file across. The receiver’s computer has a matching window waiting to receive, checks the label, and stores the file in its own mailbox folder.
- **Why it matters**: Unlike sending a single letter (HTTP), FTP lets you send large documents or entire folders quickly and reliably.
