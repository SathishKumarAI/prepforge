**Grouped‑Query Attention (GQA)** is a recent transformer tweak that splits the query set into groups and lets each group attend to only a subset of keys/values.  
*Why it matters*: In large‑scale recommendation pipelines we often process **10 M+ user embeddings per second**. Traditional self‑attention costs *O(N²)*, making inference latency prohibitive.
