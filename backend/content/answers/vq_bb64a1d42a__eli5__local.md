Imagine a recipe book that can be printed in many different ways—paper, e‑mail, PDF, or even an interactive web page. Oracle Reports is like that versatile cookbook, and each “file extension” is one of the possible formats it can produce.

- **`.rep`** – the master recipe file (the report definition).  
- **`.rpt`** – a printed version created by the Report Builder.  
- **`.pdf`, `.html`, `.rtf`, `.txt`** – the same content exported to PDF, web‑ready HTML, rich text, or plain text for easy sharing.  
- **`.xml`** – a machine‑friendly version that can be read by other programs.  

When you run a report, Oracle simply chooses which “recipe” (extension) you need and spits it out in that format. That’s all the file types you’ll see.
