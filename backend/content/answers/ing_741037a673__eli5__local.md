**Step 2: Label the Ground‑Truth Data**

Think of your dataset as a photo album of people, but you don’t yet know who each person is. “Labeling” is like writing the name on a sticky note and pasting it next to every picture so the computer can learn which face belongs to which person.

In AI evaluation, the *ground truth* is the correct answer that we already know. For a text‑generation model, ground‑truth labels might be “yes,” “no,” or a short human‑written paragraph that shows how the model should respond. By attaching these labels to each example, you give the algorithm a clear target to aim for—just as a student needs the answer key before practicing problems.

Once every data point has its correct label, the AI can compare what it predicts against the known truth and learn from any mistakes. This labeled set becomes the benchmark that all subsequent tests use.
