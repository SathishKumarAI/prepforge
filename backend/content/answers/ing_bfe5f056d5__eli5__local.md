Think of a **class** like a *blueprint* for building a house.  
The blueprint tells you what rooms the house will have, where the doors go, and how big each room is, but it isn’t a house itself.  

In programming, a class does the same: it defines the *shape* (attributes) and *behaviour* (methods) that any object of that type will share.  
When you “create” an object from the class—just as you would build a house from its blueprint—you get a concrete instance with its own rooms (data values).  

So, in CS324 we use classes to group related data and functions together so we can make many objects that all follow the same structure, just like many houses built from the same design.
