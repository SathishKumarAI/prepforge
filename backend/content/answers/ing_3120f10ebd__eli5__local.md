Imagine you’re on a long road trip and your car has two engines that can run at the same time, but only one is needed to keep you moving. If the first engine stalls, the second engine automatically starts right away so you never stop. In computing, a **failover cluster** works the same way.

A failover cluster is a group of servers (the “engines”) that share a single workload—like running a website or database. One server is active, handling all requests, while the others sit quietly in standby mode. If the active server crashes or loses power, one of the standby servers instantly takes over without any interruption to users. This automatic switch is called **failover**; it keeps services up and running even when hardware fails.
