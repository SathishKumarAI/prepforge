Think of a library that holds all the books you’ll ever read for your machine‑learning projects.  
**Data Definition Language (DDL)** are the “building‑plans” you give to the library’s catalog so it knows what kinds of books exist, where they sit, and how they’re organized.

- **CREATE TABLE** is like telling the librarian to set up a new shelf: “Here will be all the images we’ll use for training.”  
- **ALTER TABLE** lets you add a new column (a new attribute) or rename something on that shelf, just as adding a new book type.  
- **DROP TABLE** removes an entire shelf when it’s no longer needed.

In short, DDL tells the database *what* data structures look like—how they’re shaped and stored—so your machine‑learning code can later read from or write to them smoothly.
