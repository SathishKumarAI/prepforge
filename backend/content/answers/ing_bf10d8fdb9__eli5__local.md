Imagine you’re building a Swiss‑army knife for a hiking trip.  
A **tool** is like a single blade or corkscrew—handy, but only good at one job.  
A **subagent** is like the whole knife: it has many blades that work together to handle any task you throw at it.

The *overengineering trap* happens when you try to make each blade extra fancy (adding lasers, GPS, etc.) before you even know what you’ll need on the trail. You end up with a heavy, clunky gadget that’s hard to use and expensive, while the simple blade would have done the job fine.

Instead, start with a clear goal: “I need to cut rope.” Pick a single, reliable tool for that job. If later you find you also need to open cans, add another small subagent (a can opener) rather than redesigning the whole knife. Build just enough functionality—no more, no less—to keep the system light and effective.
