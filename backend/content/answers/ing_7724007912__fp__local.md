## Why a “Linked‑List” lesson is indispensable in ML engineering

In machine learning pipelines we rarely manipulate raw data *in place*; instead, we build **data structures** that expose efficient access patterns for streaming, incremental training, or online inference. A singly linked list—nodes chained by pointers—is the canonical example of a *dynamic* structure: it supports  
- `O(1)` insertion/deletion at known positions (no costly array copies), and  
- `O(n)` traversal when sequential access is required.

These properties mirror what we need in many ML workflows:

| Operation | Linked‑list cost | Typical ML use |
|-----------|-----------------|----------------|
| Append a new sample to a training buffer | `O(1)` | Online learning, replay buffers |
| Remove the oldest sample (FIFO) | `O(n)` if head not known; `O(1)` with tail pointer | Sliding‑window estimators |
| Random access for minibatch sampling | `O(n)` | Reservoir sampling, importance weighting |

Thus, mastering linked lists equips a practitioner to design **memory‑efficient** data pipelines that avoid the overhead of resizable arrays or hash tables when only sequential updates matter.

### Non‑obvious insight

**The “interleave” trick in problem 7 shows that linked lists can emulate hash tables.**  
By inserting cloned nodes immediately after originals, we create a temporary *bijection* between old and new nodes without any external map. After the cloning pass, a single traversal updates `random` pointers using only local references. This pattern—embedding auxiliary information inline—extends to many ML data‑flow problems where we need to preserve original relationships while building augmented views (e.g., attention maps on token streams). Recognizing that *pointers themselves can carry state* lets us sidestep explicit hashing and keep the pipeline lightweight.

In short, linked lists are not just a CS textbook toy; they embody the very trade‑offs—time vs. space, locality vs. dynamism—that every ML engineer wrestles with when turning raw data into predictions.
