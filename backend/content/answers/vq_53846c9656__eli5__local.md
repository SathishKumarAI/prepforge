**Typesafe in Scala**

Think of programming as building a LEGO castle.  
Each LEGO block has a *color* and a *shape*. If you try to snap a round block onto a square slot, the machine will stop—because they don’t match.  

Scala’s “types” are those colors and shapes. A **type** is simply a label that tells the compiler what kind of data a variable can hold (e.g., `Int` for whole numbers, `String` for text).  

When code is *typesafe*, the compiler checks that every piece fits its slot before you run the program. It catches mismatches—like trying to put a string into an integer field—at compile time, so bugs are caught early instead of at runtime.

In short, **Typesafe in Scala** means your program’s “LEGO blocks” always match their slots, making the code more reliable and easier to understand.
