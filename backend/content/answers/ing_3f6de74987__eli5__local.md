Think of a list as a row of dominoes you’re going to knock down.  
In machine learning we sometimes want the same domino line but flipped so the first one becomes last, the second becomes second‑to‑last, and so on—just like flipping a picture in a mirror. In Python this is done with `reversed(list)` or `list[::-1]`. It simply reads the original row from end to start without moving the dominoes physically; it just changes the order you look at them.

**Key terms**  
- **List**: an ordered collection of items (like a line of dominoes).  
- **Reverse**: reading that list from its last element back to its first.  

Reversing is useful in algorithms where the direction matters—just as a mirror image changes how you interact with the same set of objects.
