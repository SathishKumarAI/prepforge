You write the menu on a note so your friends know what’s inside: “sandwich, apple, juice.” That note is like **JSON (JavaScript Object Notation)**—a plain‑text list of key–value pairs that tells a computer exactly what data it has and how to read it. It uses simple words (“name”, “age”) and values (strings, numbers, true/false) so anyone can understand.

Now picture a backpack that stores the same lunch but with extra space for pictures, videos, or other media. That’s **BSON (Binary JSON)**—the binary version of JSON used by MongoDB. BSON keeps all the same key–value information but packs it in a compact, machine‑friendly format so databases can read and write faster.
