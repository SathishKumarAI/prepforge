Imagine you’re organizing a library of books that your computer will read later.

**Stack** – Think of a stack as a pile of plates at the kitchen counter. You can only add or remove the top plate. In programming, a *stack* keeps data in “last‑in, first‑out” order: the most recent item you put on it is the first one you take off.

**Linked List** – Picture a treasure hunt where each clue (node) points to the next clue’s location. A *linked list* is a chain of nodes; each node holds data and a pointer to the following node. You can add or remove nodes anywhere without moving the whole chain.

**Tree** – Visualize a family tree: one ancestor branches into children, who branch into grandchildren, and so on. A *tree* is a hierarchical structure where each node has zero or more child nodes and exactly one parent (except the root). It lets you search, sort, or organize data in a branching way.

These structures are the building blocks that let a machine learn by storing, accessing, and navigating information efficiently.
