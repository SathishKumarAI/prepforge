Think of a kitchen where you want to bake a cake but don’t have the ingredients or the oven.  
An **API (Application Programming Interface)** is like a menu that tells the kitchen staff exactly how to get what you need: “Give me flour, sugar, eggs, and heat the oven to 350 °F.” You just say the request; the kitchen does the work and returns the ready cake.

In computing, an API is a set of rules that lets one program ask another for data or services—just as the menu lets you order. The program (the customer) sends a *request* (your order), the other program (the kitchen) processes it, and then sends back a *response* (the cake).  
So an API is simply a standardized way for software to talk to each other without knowing how the other side works internally.
