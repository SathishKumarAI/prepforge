**Agentic Coding Patterns** are ways that programmers give a computer “personality” so it can act like an autonomous helper rather than just following a script.

Think of a robot chef in a kitchen.  
A simple recipe (procedural code) tells the chef: *mix, stir, bake.*  
An agentic pattern gives the chef extra tools: it can ask for more flour if the batter is too thin, skip a step if the oven is already hot, or suggest adding a pinch of spice to improve flavor. It learns from what happens (feedback) and makes decisions that best achieve the goal—delicious food.

In AI, these patterns let software *observe*, *plan*, and *adapt* on its own, turning code into a flexible partner instead of a rigid set‑of‑instructions machine.
