**Reference – Load Balancer (in Machine Learning)**  

Think of a busy coffee shop that serves many customers at once. A *load balancer* is the barista who decides which cup goes to which espresso machine so no single machine gets overwhelmed while others sit idle. In ML, when an app needs predictions from several models or multiple copies of the same model, the load balancer distributes each request evenly across those “machines.”  

**Reference** in this context means a *baseline* or standard version of the model that the system keeps ready. It’s like having a favorite latte recipe on hand—if a new machine breaks down, the barista can quickly switch to the reference machine and keep serving customers smoothly.  

So, the load balancer is the traffic‑cop directing requests, while the reference model is the trusted copy that always stands by to handle any request if needed.
