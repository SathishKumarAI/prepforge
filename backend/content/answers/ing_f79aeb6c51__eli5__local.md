**Code‑Based Evaluations in AI**

Think of an AI model like a chef who’s been trained to cook many dishes. A *code‑based eval* is a test that hands the chef a recipe written in a programming language (Python, for example) and asks them to write a short program that solves a specific problem—maybe sorting numbers or finding a pattern in data. The code you see is like a blueprint: it tells the AI exactly what input to expect, what steps to follow, and how to check if the answer is right.

The evaluator runs the AI’s code on hidden test cases, just as a judge would taste the chef’s dish. If the program passes all tests, the model earns points; if not, it learns where its logic falters. This method lets us measure an AI’s *reasoning* and *coding* skills in a clear, reproducible way—just like grading a math problem with a known answer.
