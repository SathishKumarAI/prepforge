Step 3—“Generate Documentation”—is like writing the recipe book that tells anyone who borrows the gadget how to use it safely and deliciously.

In practice you create files (often in Markdown) that describe:

* **What the model does** – its purpose and inputs/outputs.

* **How to run it** – installation steps, required libraries, command‑line options.

* **Versioning and licensing** – who owns the code and how it can be shared.

You then push this recipe book into GitHub (the online repository).
