Imagine building a super‑smart robot that can learn by itself. Google’s “interview loop” is the way this robot keeps improving, like a student practicing and getting feedback.

1. **Ask** – The robot asks a question or picks a task (e.g., translate a sentence).  
2. **Answer** – It tries to solve it using what it knows.  
3. **Judge** – A separate system checks how good the answer was, giving a score or pointing out mistakes.  
4. **Learn** – The robot updates its internal rules so it will do better next time.

The loop repeats millions of times, just as a chess player practices against an opponent who immediately tells them why a move was wrong. Over and over, the robot’s “brain” gets sharper, learning to answer more accurately without human help. This is how DeepMind trains models that can play Go or write code.
