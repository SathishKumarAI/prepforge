**What’s an API? Think of it as a restaurant menu.**  
In a kitchen (your computer system), chefs (the software) can only make certain dishes (functions). The menu is the *Application Programming Interface* – it lists what dishes you can order and how to order them. You tell the waiter, “I’d like a cheeseburger with extra cheese,” and they translate that into a precise request for the kitchen: “make burger, add cheese.”  

An API guarantees the waiter’s language is clear and consistent so any customer (another program) can place orders without knowing how the kitchen works. **Reliability** means the menu stays unchanged, the waiter follows it faithfully, and the kitchen always delivers what was ordered on time—so every “order” gets a correct, timely answer.
