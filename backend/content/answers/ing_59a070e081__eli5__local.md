**Pattern 1 – Agent Workflow (Linear “Swarm”)**

Imagine a relay race where each runner passes the baton to the next person, one after another, until the finish line is reached. In an *Agent Workflow*, several simple AI agents take turns working on a single problem. The first agent looks at the task and produces a draft or idea. That output becomes the input for the next agent, which refines it, adds detail, or checks for errors. Each agent only needs to know what the previous one produced, not everything that happened before. By chaining them linearly—like a human relay team—you get a complex result built from many small, focused steps without any single agent needing to be overly smart or complicated.
