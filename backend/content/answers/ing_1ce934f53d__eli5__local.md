Think of writing an email to a friend who lives far away.  
If you write the same opening (“Hey, how’s it going?”) over and over, you might keep a small note with that line so you don’t have to type it again—this is **prompt caching**. The cached part lets you focus on the new details of each message (the friend’s name, what you’re asking, your news).  

In AI, prompt caching does exactly that: it saves the reusable “template” part of a request and only changes the bits that matter for each new question. This shapes how we **engineer prompts**—we design a skeleton that can be quickly filled in with fresh context. The result is faster, more consistent answers because the AI doesn’t waste time re‑reading the same opening every time.  

So, just as you keep a note to speed up email writing, prompt caching speeds up and steadies AI responses by giving them a solid, reusable structure.
