**Load balancing** is like a friendly traffic cop that keeps requests (or data) moving smoothly through several “roads” (servers). Imagine you’re at a pizza place with five ovens. If every customer’s order goes to the same oven, it will get hot and slow. Instead, the clerk hands each new order to the next oven in line: first to Oven 1, then Oven 2, …, back to Oven 1 again. That’s **round‑robin load balancing**—a simple rule that cycles requests evenly so no single server gets stuck working too hard while others sit idle. In machine‑learning systems, this keeps training jobs, model queries, or data pipelines running fast and fair across many machines.
