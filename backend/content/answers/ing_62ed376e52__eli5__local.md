**Zero‑Shot Prompt Engineering in plain English**

Imagine you’re a chef who has never cooked a particular dish, but you have the recipe book. You read the instructions once and then try to make it without any practice or extra recipes. That’s zero‑shot learning: the model is asked to solve a new task it hasn’t seen before, using only the description you give it.

In this case “prompt engineering” is like giving that chef a clear, step‑by‑step recipe in plain language—no kitchen tricks, just straightforward instructions. The model (the chef) reads your prompt and produces an answer, even though it has never been trained on that exact question. It relies solely on the knowledge it already holds, guided by the prompt you wrote.

So: zero‑shot = “first try only”; prompt engineering = the way we phrase the first try so the model gets it right.
