**When to Use Code‑Based Evaluations in AI**

Think of a code‑based eval like a *cookbook test* for a new recipe. You already know the ingredients (the data) and you want to see if the kitchen’s stove (the model) can follow the instructions correctly. In AI, this means writing tiny programs that ask the model to perform a specific task—like translating a sentence or solving a math problem—and then checking whether its output matches the expected answer.

Use code‑based evals when:

- **You need precise, repeatable checks** (e.g., “does the model give the exact formula?”).  
- **The task involves logic or computation** that can be verified automatically.  
- **Speed matters**, because running a script is faster than human review.  

In short, code‑based evaluations are your quick, reliable taste test for tasks where you can program the expected result and let the model cook it out.
