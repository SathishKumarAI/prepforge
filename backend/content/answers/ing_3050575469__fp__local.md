1. **Scalability** – by avoiding per‑session memory, any number of agents can run in parallel on the same hardware pool without contention.
2. **Privacy & Security** – no user data lingers on Google’s side; each request is isolated and fully auditable.

The result is a lightweight agent that still respects the same Markov Decision Process assumptions as its larger counterparts.
