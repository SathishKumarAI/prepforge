Think of a code‑based evaluation like a quick, reliable test drive for a car you’re building. Instead of sending the car to every possible road and weather condition (which would be slow, expensive, and give slightly different results each time), you set up a small, controlled track with fixed obstacles—like a straight line, a single curve, and a speed bump—and run the car through it on the same engine every time. The “code” is the script that tells the car exactly where to go, how fast, and what to look for (does it hit the bump? does it stay on track?). Because the track never changes and you’re using the same engine, the results are deterministic: if the car passes today, it will pass tomorrow under identical conditions. This makes the test “fast” (it takes only a few seconds), “cheap” (no need for real‑world driving or expensive sensors), and “deterministic” (results repeat exactly). In AI, these code‑based evals let researchers quickly see how a model behaves on specific prompts or tasks without costly human judgment or variable environments.
