**1. Clarify scope & assumptions**  
- Assume the candidate knows basic CS concepts but may not have seen formal definitions.  
- Define *Artificial Intelligence* (AI) as the overarching goal: building systems that can perform tasks requiring human‑like intelligence.  
- Distinguish between *Machine Learning* (ML) and *Deep Learning* (DL) as subfields/techniques rather than separate goals.

**2. Mental model / framework**  
Use a hierarchy:  
```
AI (goal)
 └─ ML (methodology to achieve AI)
      └─ DL (specific ML technique using deep neural nets)
```
Think of it as “AI = any intelligent behavior; ML = learning from data; DL = layered learning.”

**3. Step‑by‑step reasoning**  
- Start with the broadest term: AI—what it means, why we pursue it.  
- Move to ML: explain that ML is one way to build AI by letting models learn patterns from data instead of hand‑coding rules.  
- Then DL: highlight that DL is a subset of ML that uses multi‑layer neural networks (deep nets) and excels at high‑dimensional problems like vision or speech.

**4. Common traps to avoid**  
- Don’t conflate “AI” with “ML.” AI can also be rule‑based, symbolic, etc.  
- Don’t say DL is a separate field; it’s an ML technique.  
- Avoid overloading “neural network” as the only AI tool.

**5. Sanity‑check & communication**  
- Ask: “If I drop ‘deep’ from deep learning, does the answer still hold?” It should—DL remains within ML.  
- Check for clarity by giving a quick example: “AI → autonomous car; ML → learn to recognize traffic signs; DL → convolutional nets that do the recognition.”  

By following these steps you’ll provide a concise, accurate comparison that’s easy for someone newly interested in AI to grasp.
