Imagine a language model as a child who learns by reading books (the base training). Reinforcement learning is like giving that child a game: every time it writes something useful or interesting, the child receives a small reward (a sticker). Over many rounds, the child starts to choose stories that earn more stickers—so it learns to pick sentences that are clearer, safer, and better organized.

In this sense, reinforcement learning does **not** give the model new “thinking power” from scratch; it only teaches the child how to use what it already knows in a way that earns rewards. The underlying knowledge (the base model) remains unchanged—just the *strategy* for using it is tuned. So while RL can make an LLM act more reasoned and helpful, it doesn’t add fresh reasoning capacity beyond what was learned during its initial training.
