**Context Assembly – The “Story‑Builder” for a Code Assistant**

Imagine you’re telling a story to a friend who wants to write it down. Before the friend can help, they need to know what’s happening: the characters, the setting, the plot twists so far, and where the story is going next. *Context assembly* is that gathering of all the relevant bits.

For a code assistant, the “characters” are variables and functions already written; the “setting” is the file or project folder; the “plot twists” are recent edits and comments; and the “future direction” comes from the user’s new question. The assistant collects (assembles) these pieces into one coherent snapshot and feeds it to its language model, so the model can give suggestions that fit the exact spot in your code.

**Key term explained**

- **Context assembly**: The process of gathering all surrounding code, comments, and recent changes so a tool can understand where you are and what you need next.
